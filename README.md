## 🛠️ Tech Stack

This portfolio is built using core web technologies to ensure optimal performance, accessibility, and a custom design without relying heavily on bloated frameworks:

- **HTML5**: Semantic and accessible structure.
- **Vanilla CSS3**: Custom design system, CSS variables, flexbox, grid, and modern animations (glow effects, responsive layouts).
- **JavaScript (Vanilla)**: Smooth scrolling, interactive elements, menu toggling, and dynamic active states.

## 📂 Project Structure

This portfolio is a multi-page website, designed for clean separation of concerns and easy horizontal scaling:

- `index.html`: Hero section and About Me.
- `skills.html`: Technical skills, tech stack, and proficiencies.
- `projects.html`: Showcase of the projects I've built.
- `activities.html`: Extracurricular activities, certifications, and participations.
- `contact.html`: Ways to get in touch with me.
- `style.css`: The central stylesheet containing all design tokens and utility classes.
- `script.js`: Reusable scripts for navigation, mobile menu, and interactive features across all pages.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/jayasianboyd/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your favorite web browser or use an extension like **Live Server** in VS Code.
